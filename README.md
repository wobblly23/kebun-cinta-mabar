# 🌾 Kebun Cinta Kita - Game Mabar P2P Berbasis Web 💖

Game bertani santai (*cozy farming RPG*) multipemain 2 orang (**Mabar**) yang dirancang khusus untuk dimainkan berdua bersama pasangan secara langsung melalui browser (HP atau Laptop), **100% web statis tanpa butuh server berbayar atau kartu kredit sama sekali!**

Menggunakan teknologi **WebRTC Peer-to-Peer (P2P)** via PeerJS, koneksi langsung menghubungkan perangkatmu dengan perangkat pacarmu secara instan.

---

## 🌟 Fitur Baru & Peningkatan Lengkap

### 1. 🏡 Masuk ke Dalam Rumah & Pasang Perabotan
- **Masuk Rumah**: Dekati pintu rumah lalu tekan **[E]** (atau tap **🖐️ Aksi**) untuk masuk ke dalam rumah bersama pasanganmu!
- **Tidur Bersama di Ranjang 🛏️**: Dekati ranjang tidur ganda dan tekan **[E]** untuk tidur bersama memajukan waktu malam ke pagi hari cerah (07:00 AM) serta memulihkan energi!
- **Dekorasi & Perabotan Rumah 🪑**: Beli sofa beludru merah, karpet cinta, rak buku cerita, tanaman hias monstera, dan lilin aromaterapi dari Pak Budi untuk menghias rumah kalian berdua!

### 2. 🏪 Desa Pedagang & NPC Interaktif
- **Pak Budi (Toko Tani & Perabot) 🛒**: Menjual aneka bibit sayuran (Wortel, Kentang, Tomat, Stroberi, Semangka) dan aneka perabotan rumah.
- **Mak Siti (Peternakan Hewan) 🐮**: Menjual hewan ternak mulai dari Anak Ayam Kuning, Ayam Petelur, Domba Wol, Babi Lucu, hingga Sapi Perah.
- **Paman Sam (Nelayan Danau) 🎣**: Berada di dermaga danau, menjual Alat Pancing Bambu dan membeli ikan hasil tangkapanmu!
- **Mbah Dukun (Kontraktor Bot) 🤖**: Menyewakan roh pembantu kebun otomatis jika kamu sudah mengumpulkan koin.

### 3. 📈 Sistem Progresi & Ekonomi (Mulai dari Nol!)
- **Awal Mula Manual**: Di awal permainan, kamu **hanya memiliki lahan kebun, cangkul, penyiram, dan sedikit bibit wortel**.
- **Hewan Harus Dibeli**: Padang rumput peternakan di awal masih kosong! Kamu harus menabung koin untuk membeli ayam atau sapi dari Mak Siti.
- **Bot Pembantu Harus Disewa**: Bot Slimey (penyiram) dan Boni (pemanen) baru akan muncul dan membantumu setelah kamu menyewa mereka dengan koin cinta!
- **Alat Pancing**: Harus dibeli terlebih dahulu dari Paman Sam seharga 60 koin sebelum bisa digunakan memancing di danau.

### 4. 🎣 Fitur Memancing di Danau Telaga
- Bawa alat pancing ke tepi danau atau jembatan dermaga.
- Tekan **[E]** atau **[Spasi]** untuk melempar umpan ke air.
- Tunggu tanda seru (**❗**) muncul lalu tarik pancing untuk mendapatkan **Ikan Mas 🐟**, **Gurame Telaga 🐠**, atau **Ikan Hati Romantis 💖**!
- Ikan bisa dijual untuk menambah pundi-pundi koin cinta kalian.

### 5. 🐮 Hewan Peternakan & Hasil Ternak
- Dekati hewan di padang rumput dan tekan **[E]** untuk mengelus mereka.
- Mengeluarkan partikel hati cinta ❤️ dan menghasilkan **Susu Segar 🥛**, **Telur Emas 🥚**, dan **Wol Lembut 🧶**.

### 6. 💕 Fitur Spesial Pasangan Romantis
- **Love Meter (Poin Cinta ❤️)**: Poin bertambah setiap kali berkebun, memancing, menyiram, mengelus hewan, mengirim emote, berpelukan, atau berciuman (**tombol [H]**)!
- **Siklus Waktu Pagi, Siang, Senja Romantis 🌇, dan Malam Berbintang 🌙** dengan kunang-kunang menyala ✨.
- **📷 Kamera Polaroid Selfie (Foto Berdua)**: Klik ikon kamera untuk mengunduh foto kenangan berdua bertuliskan nama kalian dan tanggal hari ini!

## 🎮 Kontrol Game

- **Di PC / Laptop**:
  - `WASD` / Panah: Berjalan
  - `E` / `K`: Interaksi / Bicara dengan NPC / Masuk Rumah / Buka Peti / Memancing / Elus Hewan
  - `Spasi` / `J`: Menggunakan Alat (Cangkul / Siram / Tanam)
  - `1 - 7`: Memilih Alat & Bibit di Hotbar
  - `H`: Mengecup / Memeluk Pasangan
  - `C`: Membuka Chatting Mesra
  - **Klik Mouse**: Bisa klik langsung pada ubin tanah atau NPC untuk berinteraksi!
- **Di Smartphone (HP)**:
  - **Virtual Joystick Analog** di kiri bawah untuk berjalan.
  - **🖐️ Aksi/Bicara [E]**: Untuk bicara dengan NPC, masuk/keluar rumah, dan panen.
  - **✨ Gunakan Alat [Spasi]**: Untuk cangkul, siram, dan tanam bibit.
  - **🔄 Ganti Alat**: Mengganti alat yang aktif.
  - **❤️ Emote**: Mengirim stiker cinta ke pacar.

## 🚀 Panduan Hosting (100% Gratis di Netlify & GitHub Pages)

### Langkah 1: Push ke GitHub
```powershell
git add .
git commit -m "feat: complete farm expansion with interior, npcs, fishing, and economy"
git push origin main
```

### Langkah 2: Aktifkan di Netlify atau GitHub Pages
1. **Lewat Netlify (Rekomendasi)**: Buka [app.netlify.com](https://app.netlify.com/), hubungkan dengan repo `wobblly23/kebun-cinta-mabar`, lalu klik Deploy.
2. **Lewat GitHub Pages**: Buka [pengaturan pages repo kamu](https://github.com/wobblly23/kebun-cinta-mabar/settings/pages), pilih branch `main`, lalu klik Save.
